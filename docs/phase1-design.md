# 第一階段設計：多租戶、公司組與到期規則

日期：2026-10-16。需求見 [`requirements.md`](requirements.md)。

## 範圍

1. 多租戶基礎：所有資料歸屬一家代辦公司（租戶）。
2. 公司組：一組＝境外公司（香港或澳門）＋內地公司，掛 1 個或多個指標。
3. 指標補充欄位：類別、口岸、所屬公司組；車輛補充港澳首次註冊日期。
4. 可設定的到期規則，以及由規則推算的到期總表。
5. 管理端：管理總覽、公司與指標、規則設定；兩地牌、車輛、公司頁可錄入到期日。

不在本階段：報帳報稅、出租合約與收租、承租方連結、工單改版、員工權限細分、用戶端改版。

## 資料表

| 表 | 用途 |
|---|---|
| `tenants` | 代辦公司（租戶）。舊資料歸入預設租戶 |
| `users.tenant_id`、`customers.tenant_id` | 帳號和客戶所屬租戶；其他資料經客戶歸屬租戶 |
| `company_groups` | 公司組：客戶、名稱、備註 |
| `companies` | 公司：所屬公司組、司法區（香港／澳門／內地）、名稱、登記號碼、成立日期、納稅人類型 |
| `plate_assets` 新欄位 | `group_id`、`indicator_category`、`port` |
| `vehicles` 新欄位 | `first_registered_on`（港澳首次註冊日期） |
| `rules` | 到期規則，每個租戶一套，可修改、停用、新增 |
| `tracked_items` | 手動錄入的到期日（例如 CRP、保險、商業登記證） |
| `rule_completions` | 推算型規則按期完成的記錄（例如 2026 年 NAR1 已交） |

## 規則

每條規則有：代碼、名稱、對象（兩地牌／公司／車輛）、套用條件、計算方式、參數、提前提醒天數、啟用狀態。

套用條件可按：路線（粵港／粵澳）、司法區、指標類別、口岸、車輛來源地。空白代表全部適用。

| 計算方式 | 說明 | 例子 |
|---|---|---|
| `expiry` | 讀取手動錄入的到期日；未錄入時列為「待錄入」 | 批文、CRP、澳門通行證、保險、商業登記證 |
| `anniversary` | 以公司成立日的周年日加偏移天數 | 香港 NAR1：周年日後 42 天 |
| `yearly` | 每年固定月日 | 內地工商年報 6 月 30 日、匯算清繳 5 月 31 日 |
| `inspection` | 按港澳首次註冊年數推算驗車或領標誌 | 第 2、4、8 年領標誌，第 6 年上線檢驗，第 10 年起每年檢驗 |

預設規則依 2026-10-16 官方核對結論建立，見 `api/src/rules.js`。租戶可在管理端調整提醒天數、條件與參數。

## 到期狀態

| 狀態 | 條件 |
|---|---|
| 已逾期 | 到期日已過且未完成 |
| 需處理 | 距到期日不超過規則的提醒天數 |
| 即將到期 | 在總覽查看範圍內（預設 90 天） |
| 待錄入 | `expiry` 規則適用但未錄入日期，或推算所需日期缺失 |

推算型項目由管理員標記「本期已完成」，系統即轉到下一期。

## 租戶隔離

- 管理員只能讀寫自己租戶的客戶；車輛、兩地牌、案件、公司、到期項目均經客戶歸屬檢查。
- 客戶帳號仍只能看到自己的資料。
- 規則、到期項目和完成記錄都帶 `tenant_id`。
