# 同行業務調查與功能缺口（2026-10-16）

資料來自香港、內地同行網站及政府公告。同行網站屬宣傳，價錢只作參考。

## 一、同行提供的業務

| 業務 | 香港同行 | 內地同行 | 我們系統現況 |
|---|---|---|---|
| 新辦指標（投資類、高新企業類、人才、資格類） | ✅ | ✅ | 舊案件流程有，未按新結構整理 |
| 批文續期、禁區紙（CRP） | ✅ | ✅ | ✅ 到期規則 |
| 海關及邊檢備案（每年） | ✅ 約 ¥980／年 | ✅ | 只作工單最後一步，**沒有獨立到期** |
| 海關監管簿、檢驗檢疫簿續期、海關擔保函 | ✅（監管簿已取消） | — | 不做 |
| 換車（舊車退港 → 新車登記 → 臨時牌 13–15 天 → 驗車 → 備案） | ✅ | ✅ | 只有工單類型，沒有步驟清單 |
| 換司機（一主兩副） | ✅ | ✅ | 司機只從批文卡讀出，**沒有司機證件到期** |
| 內地違章代繳 | ✅ | ✅ | ❌ |
| 兩地保險 | ✅ | ✅ | ✅ 到期規則 |
| 公司維護（香港秘書、內地工商代理、年審、報稅） | ✅ | ✅ 常與代理記帳、掛靠地址打包 | ✅ 規則；**缺註冊地址／掛靠地址合約到期** |
| 現牌買賣（實際是轉讓持牌公司股權） | ✅ 港珠澳 ¥18 萬、深圳灣 ¥28 萬、皇崗 ¥80–120 萬 | ✅ | ❌（只有客戶之間轉讓） |
| 託管代售 | ✅ | — | ❌ |
| 指標出租 | ✅ 深圳灣 ¥5,000／月＋按金 ¥6 萬；港珠澳 ¥1,500／月 | ✅ | 排隊中 |
| 指標回收／退牌 | ✅ | — | ❌ |
| 七人車接送、陪同過關 | 部分 | — | 不做 |

維護收費參考：每年 ¥7,800–¥20,000 不等，有的按月 ¥700 起；新辦分三期收（定金 → 稅款 → 尾數），政府規費與代辦費分開列。

## 二、需要管理者注意的合規風險

廣東省公安廳 2019 年措施（[香港政府新聞公報](https://www.info.gov.hk/gia/general/201904/01/P2019040100540.htm)）原文：配額持有人或使用人如**轉讓、出租、出售配額**，有關配額將被註銷。

- 同行仍普遍經營「出租」和「買賣」：買賣以轉讓持牌公司股權方式進行；出租時承租方車輛登記到持牌公司名下。
- 系統會保存出租合約、承租方連結、轉讓記錄。這些記錄本身可能成為不利證據。
- **負責人不自行修改業務規則**，但建議管理者：出租合約範本先讓律師看過；系統對外（承租方連結、客戶端）的用語由管理者決定；考慮合約範本不寫「出租指標」字眼。

## 三、建議補充的功能

管理者 2026-10-16 決定：除 E 外全部要做；排期見 `docs/requirements.md` 第 5.8 節。

### A. 到期規則補充（工作量小，可併入委託範圍任務）
1. 海關及邊檢備案（每年）
2. ~~海關監管簿~~（已取消）；新批文 6 個月內完成海關邊檢備案
3. 司機證件：回鄉證、香港身份證、香港及內地駕駛證；按牌照的主司機、副司機
4. 香港公司註冊地址／秘書服務合約、內地公司掛靠地址合約

### B. 司機管理（新）
- 司機成為獨立資料：姓名、證件號碼、各證件到期、與哪個牌照備案（主／副）
- 換司機工單完成後自動更新備案關係

### C. 工單步驟範本（併入「工單改版」）
- 換車、換司機、續期、新辦、備案、退牌各有步驟清單、所需文件、預計天數
- 換車臨時牌有效期 13–15 天，要倒數提醒

### D. 收費與代墊（新，月報的前提）
- 收費項目：年費、每單代辦費、租金抽成；**政府規費與代辦費分開記**
- 分期收款（定金、稅款、尾數），每期客戶確認
- 代墊費用（規費、罰款、保險）向客戶收回
- 報價單：逐項列出

### E. ~~違章記錄~~（管理者 2026-10-16 決定不做）
- 按車輛記錄違章、罰款、扣分、是否代繳、代繳金額轉入代墊

### F. 現牌買賣與託管代售（新，視管理者是否經營）
- 待售牌照清單（口岸、類別、價錢）、意向買家
- 買賣步驟：盡職調查 → 股權轉讓 → 舊車退港 → 新車登記 → 驗車 → 備案
- 完成後用「轉讓」把牌照搬到新客戶

### G. 內地公司納稅記錄（新）
- 新辦或增加投資類指標要看納稅額（門檻見第四節官方通告，按口岸和方向不同）
- 每年記錄每間內地公司已納稅額，顯示是否夠條件增辦

### H. 粵澳特有事項（待管理者補充業務量後再做）
- 澳門驗車與內地驗車兩套（「一車兩驗」）
- 兩地保險須向內地保險公司投保

## 四、管理者確認及官方核實結果（2026-10-16）

- ✅ **車輛須約每 90 天過關一次**（管理者確認）→ 新增功能 I
- ✅ **海關監管簿已取消**（管理者確認）→ A 項不加監管簿；海關擔保函亦不做，除非管理者另行要求
- ✅ **新辦投資類指標納稅門檻**（[廣東省公安廳交管局 202104 號通告](https://gdga.gd.gov.cn/jgj/gggs/content/post_3752717.html)，2021-12-31 發布，2022-01-01 起網上辦理）：

| 口岸與方向 | 計算期間 | 門檻 |
|---|---|---|
| 深圳灣、沙頭角、蓮塘：香港入境；拱北、橫琴、港珠澳大橋：澳門入境 | 上一年度 | ≥ ¥15 萬 |
| 港珠澳大橋：香港入境 | 近三年累計 | ≥ ¥10 萬 |
| 深圳灣、沙頭角、蓮塘：內地出港 | 上一年度 | ≥ ¥100 萬 |
| 港珠澳大橋：內地出港 | 近三年累計 | ≥ ¥100 萬 |

  - 可補錄近 5 年在同一內地企業投資期間的完稅證明；高新技術企業條件申辦的不用填納稅憑證
  - 增辦第 2、3 個：[公安廳 2023 年頁面](http://gdga.gd.gov.cn/jgj/jtzn/content/post_4130906.html)（非港珠澳大橋口岸）列 ¥15 萬第 1 個、¥50 萬第 2 個、¥100 萬第 3 個
  - 另：批文取得後 **6 個月內**須到海關、邊檢完成備案（2019 年政策解讀）→ 併入 A 項
  - 這些數字寫成可設定的規則參數，不寫死在程式；功能 G 按口岸＋方向＋期間計算

### I. 90 天過關提醒（新）
- 每部車記錄最近一次過關日期（員工錄入，或客戶／司機在客戶端按「已過關」）
- 第 75 天提醒、第 90 天逾期（天數可在規則設定）
- 空置或長期停放內地的車最容易漏，今日工作要列出
