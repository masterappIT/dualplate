# 交互與跨端資料驗收

日期：2026-10-15。

## 本輪修正

- 管理端工作區新增常駐的錯誤和成功提示；案件進度、辦理節點、牌證和驗車更新後有明確回饋。
- 節點、牌證或驗車狀態更新被 API 拒絕時，重新載入伺服器狀態，避免下拉欄維持未儲存的選項。
- 總覽「辦理中案件」數字連到對應篩選；案件列表補齊所有可用狀態。
- 管理端建立案件時切換路線或客戶，會清除不再適用的車輛選擇；切換路線也會重新選擇可用服務類型。
- 客戶提交成功後，立即將新案件加入「我的要求」；後續列表讀取失敗不會再把已提交的要求顯示為提交失敗。
- 客戶端案件詳情在從其他頁面返回時重新讀取，可看見管理員更新的進度。

## API 端到端驗收

使用獨立的 SQLite 演示資料庫和 4117 測試埠，不改動現有演示資料。以下情境全部通過：

| 情境 | 結果 |
|---|---|
| 客戶提交換車要求，管理端案件列表可見 | 通過 |
| 管理員更新案件狀態及說明，客戶查詢可見 | 通過 |
| 客戶嘗試改動案件及任務 | 403 拒絕 |
| 另一客戶查詢非本人案件與車輛 | 404 拒絕 |
| 辦理節點未完成時結案 | 409 拒絕 |
| 管理員新增／核對牌證、建立／更新驗車任務，客戶查詢可見 | 通過 |
| 粵港與粵澳新申請：未完成廣東批文節點即開始港／澳申請 | 409 拒絕；完成前置節點後可更新 |

管理端、客戶 H5、微信小程序及 App 資源編譯均通過。瀏覽器自動操作工具本輪無法連到本機服務，因此上述結果是 API 交互與編譯驗證，**不是瀏覽器點擊或微信／App 真機驗收**。正式交付前仍需在目標設備檢查觸控、鍵盤、安全區、載入與錯誤提示的實際畫面。
