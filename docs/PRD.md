# 粵港澳兩地車牌代辦 CRM：首版需求

版本：0.1　｜　日期：2026-10-15　｜　狀態：需求基線；實作範圍見 implementation.md

## 1. 產品定位

服務對象是提供跨境車牌及牌證代辦服務的團隊，以及其個人或企業客戶。系統處理從新申請諮詢、資格初篩、收件、代辦、交付，到後續續期提醒與客戶維護的完整關係。

**首版服務線**：粵港兩地牌、粵澳兩地牌。每條服務線仍須細分車輛來源、申請人類型、指標／配額類型及通行口岸；不可只以「粵港」「粵澳」兩個標籤決定申請條件。港澳常規配額、港車北上、澳車北上、橫琴單牌車先保留為可擴展的獨立服務線，不混入兩地牌規則。

## 2. 已核實的官方業務事實

| 事項 | 官方依據 | 對系統的含義 |
|---|---|---|
| 粵港新申請須先取得廣東省公安廳批文，再以 TD547D 向香港運輸署申請封閉道路通行許可證（CRP） | [香港運輸署](https://www.td.gov.hk/tc/public_services/licences_and_permits/closed_road_permit_for_cross_boundary_vehicles/how_to_apply_for_closed_road_permit_for_boundary/index.html) | 新申請案件要有「廣東批文」及「香港 CRP」兩個依賴階段 |
| 粵澳車輛申請澳門海關車輛邊境通行證前，須先完成廣東省公安廳的粵澳兩地牌流程；澳門海關列出車主、車輛、批文、司機及代辦授權文件 | [澳門政府首次申請](https://www.gov.mo/zh-hant/services/ps-1455/ps-1455a/) | 新申請要有獨立的澳門海關收件及電子標籤步驟 |
| 廣東公安廳的新申請指引按申請類別列出不同條件；例如「境外商戶申請香港入出內地商務車指標（非港珠澳大橋口岸）」有其專屬條件與文件 | [廣東省公安廳業務指引](https://gdga.gd.gov.cn/jgj/jtzn/content/post_4130906.html) | 資格初篩必須先選子類型，不能使用單一通用門檻 |
| 香港 CRP 續期、換車、更改司機資料使用 TD547；新辦使用 TD547D | [香港運輸署](https://www.td.gov.hk/tc/public_services/licences_and_permits/closed_road_permit_for_cross_boundary_vehicles/how_to_apply_for_closed_road_permit_for_boundary/index.html) | 新申請與後續維護使用不同案件模板及文件清單 |
| 澳門海關允許車主或其代理人辦理首次申請，特定情況需授權書及代辦人身份文件；車輛如有抵押需相應證明 | [澳門政府首次申請](https://www.gov.mo/zh-hant/services/ps-1455/ps-1455a/) | 授權、抵押狀態與代辦人文件須設為條件式收件項 |

上述來源的發布時間不盡相同。較早的流程頁只用於設計案件階段參考；上線時須逐項重新核對目前的主管部門要求，不將舊頁的地址、費用或處理時限寫死在程式中。

## 3. 使用者與權限

| 角色 | 主要操作 |
|---|---|
| 客戶／企業授權聯絡人 | 提交新申請需求、查看報價與進度、上傳文件、確認授權、接收待辦及續期提醒 |
| 銷售／客戶經理 | 線索跟進、初步分類、報價、建立客戶與案件、維護聯絡紀錄 |
| 案件專員 | 核對文件、安排提交／驗車／領證、更新官方回覆及案件狀態 |
| 審核主管 | 審核資格初篩結論、報價、關鍵狀態變更與交付 |
| 管理員 | 配置服務線、案件模板、提醒規則、權限、官方來源版本 |

客戶僅可見其獲授權的個人／企業、車輛及案件。敏感證件檔案按角色授權查看，下載與變更均留存操作紀錄。

## 4. 新申請代辦：首版核心功能

### 4.1 從諮詢到開案

1. 客戶填寫意向：粵港或粵澳、車輛來源地、個人／公司、車輛用途、預計口岸、是否已有指標／批文／車輛。
2. 系統建立**線索**，指定客戶經理，記錄來源渠道、需求、跟進時間、溝通紀錄。
3. 客戶經理選擇官方適用的**申請子類型**；如無法判定，標記「待人工核實」，不可自動聲稱合資格。
4. 根據該子類型顯示官方條件與所需文件，逐項記錄「已確認／待補件／不適用／待官方確認」。資格初篩結論需附官方來源版本與審核人。
5. 建立報價、服務範圍、代辦授權與收款記錄。報價區分**政府規費、第三方費用、代辦服務費**，不得混為一項；金額以當次核實資料為準。
6. 客戶接受後轉為正式案件，保留線索與報價歷史。

### 4.2 粵港新申請案件模板

預設階段：**資格與類型核實 → 廣東申請資料收齊 → 廣東申請／審批 → 批文取得 → 香港 TD547D 資料收齊 → 香港 CRP 提交／審批 → 其他相關備案及交付核對 → 完成並建立維護台帳**。

「批文取得」是香港 CRP 提交的前置條件，依[香港運輸署指引](https://www.td.gov.hk/tc/public_services/licences_and_permits/closed_road_permit_for_cross_boundary_vehicles/how_to_apply_for_closed_road_permit_for_boundary/index.html)設定。廣東指標申請條件必須依所選申請子類型及當前官方指引載入；例如非港珠澳大橋口岸的境外商戶商務車指標，有獨立的[廣東公安廳指引](https://gdga.gd.gov.cn/jgj/jtzn/content/post_4130906.html)。

### 4.3 粵澳新申請案件模板

預設階段：**資格與類型核實 → 廣東申請資料收齊 → 廣東申請／審批 → 批文取得 → 澳門車輛與車主文件收齊 → 澳門海關通行證申請 → 電子標籤／相關備案核對 → 完成並建立維護台帳**。

澳門海關首次申請所列文件包括車主身份或商業登記、車輛登記摺、汽車所有權資料、批文卡、核准司機身份資料，並視情況加入授權和抵押證明；以[澳門政府頁面](https://www.gov.mo/zh-hant/services/ps-1455/ps-1455a/)為準。廣東公安廳有粵澳小汽車新辦流程頁，但其發布於 2019 年；流程細節只作人工核對線索，不能自動套用為現行辦理承諾。[廣東省公安廳流程頁](https://gdga.gd.gov.cn/jgj/jtzn/content/post_2278464.html)

### 4.4 新申請專用狀態

內部狀態：`待分類`、`待資格核實`、`待報價`、`待授權`、`待收件`、`待提交`、`官方審批中`、`待客戶配合`、`待領證／標籤／備案`、`待交付審核`、`已完成`、`暫停`、`不符合當前條件`。

客戶狀態以易懂的文字顯示，並附「下一步」「需客戶提供的資料」「負責專員」「最近更新時間」。官方審批結果只根據實際回執或證件更新，不根據預計時限自動轉為成功。

## 5. 續期與其他代辦

- 每輛車分別記錄指標、批文、香港 CRP、澳門通行證、保險、司機證件及其他相關牌證的有效期與文件版本。不同類型的提醒規則分開管理。
- 續期提醒先通知內部專員，再按客戶同意的渠道通知客戶；記錄發送時間、送達／回覆及後續案件。
- 粵港 CRP 可於屆滿前四個月申請續期；廣東公安廳所述屆滿前 60 天延期窗口只針對其答覆中的數字開頭投資類指標，不作通用規則。[香港 TD547 須知](https://www.td.gov.hk/filemanager/en/content_1129/TD547_Rev%201%202026_eng_editable.pdf)、[廣東省公安廳答覆](https://gdga.gd.gov.cn/bsfw/zsk/jj/content/post_4224457.html)
- 維護案件類型：續期、換車、換司機、資料變更、補領。每種業務使用自己的官方文件清單、前置條件及進度模板。
- 同一客戶可有多輛車，同一車可有多次案件。新申請完成後自動建立下一次檢查任務，但實際有效期須由交付證件上的日期錄入並核對。

## 7. 首版頁面

1. **總覽工作台**：今日待辦、待收件、官方審批中、臨期牌證、逾期案件。
2. **線索列表／詳情**：新申請諮詢、資格初篩、溝通紀錄、報價與轉案件。
3. **客戶詳情**：聯絡人、企業、車輛、歷史案件、合約與跟進。
4. **案件詳情**：時間線、階段、文件清單、提交記錄、下一步、內部備註。
5. **車輛與牌證台帳**：各證件有效期、核對狀態與維護任務。
6. **提醒中心**：即將到期、已逾期、客戶未回覆與處理紀錄。
7. **客戶入口**：需求提交、進度查看、文件上傳、代辦授權與提醒。
8. **規則與模板管理**：服務線、申請子類型、文件清單、官方來源、提醒規則。

## 8. 首版驗收標準

- 新客戶可提交粵港或粵澳新申請意向；員工可完成分類、資格初篩、報價、授權、開案與全程跟進。
- 粵港新申請在未記錄有效廣東批文前，不顯示香港 CRP 為「可提交」。
- 粵澳新申請可按車主為個人／公司、是否代理、是否抵押，顯示相應澳門海關文件項。
- 每個資格條件與文件項能追溯到官方連結和核對日期；不明確的條件顯示「待人工核實」。
- 交付時能錄入各證件實際有效期，並建立分證件維護提醒。
- 客戶只看得到被授權的案件；內部重要狀態與文件下載留有審計記錄。

## 9. 待業務確認

這些是產品範圍選擇，不是官方資料缺口：

- 首版優先服務哪些申請子類型（例如境外商戶商務車、內地公司出境車、個人資格類型）？
- 是否需要線上報價、電子簽署與收款，或首版只記錄線下結果？
- 客戶通知優先使用甚麼渠道（短信、電郵、微信等），以及是否需要多語言？
- 代辦團隊是否跨香港、澳門、廣東三地分工？

未確認前，資料結構與流程模板保持可配置；不將某一子類型的條件推廣至所有新申請。

## 10. 目前可運行版本與需求差距

已交付的首版源碼與運行方式見 [`implementation.md`](implementation.md)。目前支援客戶要求提交、車輛／牌證查看、案件節點及驗車紀錄，管理員可開戶、受理、更新進度。第 4、7、8 節的完整商業工作流仍有未實作部分：資格證據審批、正式報價與支付、代辦授權簽署、文件上傳及版本、司機台帳、官方回執附件、外部通知與消息送達、全面的文件操作審計。這些功能完成並通過個資安全檢查前，系統只適合本機演示，不應處理真實身份證件和牌證原件。
