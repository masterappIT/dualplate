## 二、本產品的風格：「車牌管家」

**定位：簡潔、商務、工具化。** 給代辦公司每天處理到期、工單、收租用；看起來穩重可靠，資訊一眼看清。

| 方面 | 本產品做法 | 與腳手架的區別 |
|---|---|---|
| 主色 | 深松綠 `#16745D`（主按鈕、連結、選中） | 腳手架用藍 |
| 側欄 | **深色實心**側欄 `#173D34`，選中項 `#245C49` 加左側亮綠指示條 | 腳手架是淺色玻璃導航軌 |
| 表面 | **實心白卡片**＋1px 細線 `#E3E8E4`，頁面底色 `#F4F6F4`；不用透明、模糊、漸變 | 腳手架是玻璃材質 |
| 圓角 | 6（控件）／8（卡片、彈窗）／10（大面板）；膠囊 999 | 腳手架 8–24 |
| 陰影 | 只有兩級：`--e1: 0 1px 2px rgba(16,40,30,.06)`；浮層 `--e2: 0 8px 24px rgba(16,40,30,.12)` | 腳手架三級＋強調光暈 |
| 字體 | 系統字體，繁體優先：`-apple-system, "PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif`；日期與車牌號用等寬數字（`font-variant-numeric: tabular-nums`） | 腳手架簡體優先 |
| 字號 | 正文 14、表格 13、輔助 12、區塊標題 16、頁標題 22；統計數字 26（不用 40–56 的大讀數） | |
| 密度 | 控件高 36、表格行高 48，與腳手架相同 | 相同 |
| **標誌性元素** | **`PlateChip` 車牌徽章**：內地「粵Z…港」用黑底白字、香港車牌黃底黑字、澳門車牌白底黑字的小型仿真車牌；全站凡顯示車牌都用它，一眼認出是哪部車 | 本產品獨有 |
| **標誌性元素** | **`DueDate` 到期徽章**：日期＋「還有 N 天／逾期 N 天」＋狀態色，全站凡到期日都用它 | 本產品獨有 |
| 暗色模式 | V1 不做；token 按腳手架方式組織，日後可加 | |

**狀態色只有五種，全站一致（顏色＋文字，不只靠顏色）：**

| 狀態 | token | 色 | 文字範例 |
|---|---|---|---|
| 已逾期 | `--status-overdue` | `#CF3A2B` | 已逾期 12 天 |
| 快到期 | `--status-due` | `#C77700` | 30 天後到期 |
| 正常 | `--status-ok` | `#2E8B57` | 正常 |

## 四、組件清單

**從腳手架移植（保留 API 與交互，換成本產品樣式）：**
`Button`、`IconButton`、`Field`、`TextInput`、`Select`、`Checkbox`、`Switch`、`Segmented`、`Tag`、`StatusTag`、`Avatar`、`Panel`、`PageHeader`、`DataTable`、`Pagination`、`Modal`、`Drawer`、`EmptyState`、`HoverCard`、`ToastHost`、`ConfirmHost`；`ListPage`、`SearchForm`、`FormDialog`、`BoardView`；`AppShell`、`Sidebar`、`Topbar`、`CommandPalette`。

**本產品新增（登記於此）：**

| 組件 | 作用 |
|---|---|
| `DateInput` | 日期輸入（腳手架沒有）：鍵盤可輸入 `YYYY-MM-DD`，也可點開原生日期選擇；與 `TextInput` 同外觀 |
| `DueDate` | 到期徽章；`editable` 時點擊變 `DateInput`，選定即觸發 `save`，儲存中顯示載入、失敗還原並提示 |
| `PlateChip` | 車牌徽章（見第二節） |
| `StatCard` | 統計數字卡（取代腳手架 `Metric` 的大讀數），可點擊作篩選 |
| `KeyValue` | 詳情頁「標籤：值」清單，窄螢幕改單欄，不可省略標籤 |

**不移植：** 只有純外觀語彙 `Ruler`、`SpecPlate`、`SectionLabel` 的英文眉標、`instruments.css` 的斜線與深色銘牌、`AppearanceDialog`（V1 不做暗色）。**所有交互動畫都移植**（管理者 2026-10-16：「裡面所有的交互動畫我都喜歡」），對應見第九節，於第 11.6 輪起移植。

規則：
- 新頁面先找現有組件；沒有才新增到 `ui/` 或 `business/`，並在上表登記
- 頁面 `<style>` 只可寫版面排列（grid、間距、對齊），不可寫顏色、字號、圓角、陰影；這些只能來自 token
- `npm run check` 包含樣式規則檢查，違反即失敗

## 五、頁面骨架

```
Sidebar（深綠實心） │ Topbar：麵包屑 ………… ⌘K 搜尋 · 今日日期 · 使用者
                   │ PageHeader：標題 + 一句說明 ……………… [次要] [主要]
                   │ （可選）StatCard 一列
                   │ SearchForm / Segmented 篩選
                   │ Panel：DataTable（勾選後底部浮條批量操作）→ Pagination
```

- 每頁最多一個主要按鈕
- 詳情頁：返回連結 → 標題＋狀態 → `Segmented` 或分頁切換 → 內容；摘要用 `KeyValue`
- 新增／編輯：欄位 ≤ 6 用 `FormDialog`（Modal）；更多或要邊看邊填用 `Drawer`
- 不可逆操作用確認框寫清楚後果；結果用 toast

## 六、用語與文字

- 白話短句；按鈕動詞開頭；不用技術詞（規則→到期事項、參數→怎樣計算、節點→步驟、案件→工單）
- 不加英文眉標（腳手架同樣的規範）；頁面位置由麵包屑承擔
- 日期 `YYYY-MM-DD`；金額帶幣種 `HK$ 1,200`、`¥ 1,200`、`MOP 1,200`
- 不用「境外」（見 `AGENTS.md`）

## 七、響應式與無障礙

- 820px 以下側欄改抽屜（沿用腳手架）；表格在容器內橫向滾動，**操作欄吸附右側**；頁面整體不可橫向溢出
- 390px 下表單、標題、按鈕可換行，主要操作可達；不可刪去標籤和單位
- 對比度 WCAG AA；鍵盤可操作；焦點可見；圖示按鈕有中文 `aria-label`；尊重「減少動態效果」
