## 二、本產品的視覺識別：「證件感」

管理者 2026-10-16 再次強調：**必須有自己的視覺風格；操作風格可以用（腳手架、Wot）**。所以交互照用，外觀全部按本節自己做，管理端和客戶端一致。

### 概念

這個產品管理的是**官方證件**：批文卡、通行證、車牌、商業登記證。視覺語言取材於這些證件——紙質、防偽底紋、印章、票根、車牌——讓人一看就知道是「管兩地牌的系統」，而不是任何一個通用後台。

### 形狀與質感

| 元素 | 做法 | 用在 |
|---|---|---|
| **防偽底紋** | 極淡的細線扭索紋（guilloche，SVG 生成，透明度 4–6%） | 登入畫布、首頁主卡、牌照詳情頁首、月報封面 |
| **票根分隔** | 卡片內用一排小半圓缺口＋虛線分隔「摘要」與「明細」 | 牌照卡、工單卡、收款單 |
| **印章** | 圓形雙線印章，內寫狀態字（「已辦好」「已收款」「已核對」）；完成時「蓋章」動效：輕微放大→壓下→墨色擴散 | 標記完成、結案、確認收款 |
| **車牌徽章 `PlateChip`** | 縮小版仿真車牌：內地「粵Z…港」黑底白字、香港黃底黑字、澳門白底黑字；**沿用客戶端現有 `MainlandPlate.vue`、`HongKongPlate.vue` 的比例與字形**，做成小尺寸 | 凡顯示車牌處 |
| **到期徽章 `DueDate`** | 日期（等寬數字）＋「還有 N 天／逾期 N 天」＋左側狀態色條 | 凡顯示到期日處 |
| 圓角 | 4（控件）／8（卡片）／12（大面板）——比通用後台更「方正」，像證件 | |
| 陰影 | 幾乎不用；以細線和紙色層次區分，浮層才有 `0 12px 32px rgba(11,59,48,.14)` | |
| 線條 | 1px 暖灰細線；重要分隔用雙細線（證件格線感） | |

### 字體

- 系統字體，繁體優先：`-apple-system, "PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif`
- **車牌號、日期、金額、批文號**一律等寬數字（`font-variant-numeric: tabular-nums`，車牌另加 `letter-spacing: .04em`），像證件上的編號
- 頁標題 22／區塊 16／正文 14／表格 13／輔助 12；統計數字 28，字重 700

### 動效（交互沿用腳手架，配上本產品的「證件」語彙）

- 沿用腳手架 `motion.ts` 的全部語態與時長
- 本產品增加：**蓋章**（完成類操作）、**翻證**（批文卡已有的翻轉，推廣到牌照卡正反面）、**票根撕開**（打開詳情時摘要與明細沿票根線分開展開）
- 登入畫布：腳手架的節點網絡交互不變，外觀改為深通行綠底＋淡防偽底紋，節點是口岸與牌照，脈衝用牌照黃

## 九、動態視圖對應（第 11.6 輪起；2026-10-16 按管理者「要搬到有用的地方，不要為了做而做」重新篩選）

**原則：每個動畫都要回答「它幫用戶看懂或做到甚麼」。答不出就不做。** 動效只用在三類地方：
1. **回饋**：操作有沒有成功（按鈕漣漪、蓋章、儲存失敗輕搖、浮條升起表示已選中）
2. **方向**：東西從哪裡來、到哪裡去（彈窗從觸發點展開、抽屜從列表行長出、下鑽與返回）
3. **看懂數據**：結構、時間、密度一眼看清（畫布、時間軸、熱力格、數字滾動落定表示數據已更新）

**能做成動態的就不做靜態**（管理者 2026-10-16）：同一份資訊，若動態呈現（數據進場生長、狀態變化有過渡、可下鑽、可拖動）能讓人更快看懂或操作，就用動態；靜態只留給純文字與表單。但純裝飾、會拖慢日常操作的不做。高頻操作（每天幾十次的填日期、打勾）動效要短（≤ 200ms）且不阻擋下一步。

外觀換成本產品（紙面、通行綠、白底節點、狀態五色；中心節點用「客戶印章」）。每個視圖都是 `ListPage` 的 `altView`，可切回表格，偏好按頁記住，820px 以下首次預設表格。
