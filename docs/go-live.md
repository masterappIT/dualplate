# 上線清單（車牌管家 V1）

技術操作見 [Google Cloud 正式部署](./deploy.md)。

## 一、開放前

1. 確認 `dualplate-511819` 的 VM、獨立磁碟、兩個 A 紀錄和兩個 HTTPS 網址正常。
2. 兩個網域的 `/api/health` 都回 `ok: true`、`database: ok`；管理端和客戶端登入頁可開啟。
3. 手動執行一次備份並確認 GCS 有完整副本；快照排程已啟用。
4. 建立第一個管理員，登入後立即改密碼，再為每位員工開帳號。
5. 設定顧問、委託範圍、到期提醒與合約範本；用已核對資料在正式環境重跑導入。
6. 微信小程序上架另外安排，需要符合小程序網域要求。

## 二、試行

第一週由內部員工使用，每日看錯誤記錄和備份。第二週才逐位開放客戶；開放前核對牌照、批文卡、到期日與客戶權限。正式資料不從本機資料庫直接複製。

## 三、事故處理

程式故障先用 `deploy/vm/rollback.sh` 切回上一組映像摘要，檢查健康端點。資料問題先保留現況與操作記錄，再由負責人依 [部署文件](./deploy.md) 的還原步驟處理。若客戶看到別人的資料，立即停用該帳號並保存證據。
