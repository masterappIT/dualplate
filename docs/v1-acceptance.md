### 2. 情境演練

以下按畫面實際步驟數計算，**未用碼錶實測**：

| 角色 | 情境 | 步驟 | 對照標準 |
|---|---|---|---|
| 管理者 | 早上看今日工作並派工 | 打開即見四格與隊列；派工＝打開工單 → 選負責人 → 儲存（3 步） | 符合 ≤ 3 次點擊 |
| 管理者 | 新客戶 5 個牌照 Excel 建檔並套用委託範本 | 匯入 CSV（預覽逐列錯誤說明 → 確認）→ 客戶頁「套用委託範本」 | 流程具備；未計時 |
| 員工 | 收到 CRP 新證更新到期日 | 今日工作該行直接改日期 → 儲存 | 不用離開今日工作 |
| 員工 | 換車工單全流程 | 開單 → 標客戶提供 → 客戶手機收通知上傳 → 確認收妥 → 結案更新日期 | 每步有下一步提示；客戶上傳後工單頁顯示 |
| 員工 | 香港公司客戶自理後不再派工 | 委託矩陣設客戶自理 → 今日工作不出現 | 有測試覆蓋 |
| 管理者 | 每月確認月報 | 月報列表 → 打開 → 確認並發給客戶 | 每位客戶 2 次點擊 |
| 管理者 | 記一筆代收使用費並結算 | 合約 → 登記收款；或確認承租方憑證；代收結算 → 標記已結算 | 符合 |
| 客戶 | 第一次登入看懂牌照 | 首頁上方三格＋3 步導覽 | 未找真實客戶測試 |
| 客戶 | 拍照上傳文件 | 辦理進度 → 上傳 → 選相片 | H5 已驗證選單；未在真機拍照 |
| 客戶 | 開 90 天過關提醒並記錄過關 | 牌照 → 開關 → 今天已過關 | 2 次點擊 |
| 客戶 | 看上月報告淨額 | 我的 → 月報 → 打開 | 封面即見「應付給你」 |
| 承租方 | 連結看使用費並上傳憑證 | 打開連結 → 輸入電話末 4 碼 → 上傳 | 不用登入；手機寬度已驗證 |
