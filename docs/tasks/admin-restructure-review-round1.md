# 管理端結構重整：第 1 次驗收退回

負責人重跑：`npm test` 90/90 通過；`npm run check`、admin build、mobile build:h5 通過。後端大致合格。以下必須修正（畫面風格問題另由「設計系統」任務統一處理，本輪**不要**改樣式）。

1. **CSV 匯入會把現有牌照搬離原公司組**（嚴重）：現有牌照已屬某公司組，CSV 的公司名稱與該組不符（例如打錯字「曲坤有限公司X」）時，現在會新建公司組並把牌照搬過去，預覽只顯示「新增公司組」。改為：現有牌照已有公司組而名稱不符時，該列標錯誤「公司名稱與現有公司組（某某 · 某某）不符；如需更換公司組請在牌照詳情處理」，不可寫入。新牌照或現有牌照沒有公司組時維持現行做法。補具名測試。
2. **日期格式太嚴**：Excel 另存 CSV 常見 `2026/11/20`、`2026/1/5`、`2026-1-5`。全部接受並轉成 `YYYY-MM-DD`；其他格式才報錯，錯誤訊息舉例正確寫法。補具名測試。
3. **非 UTF-8 檔案**：前端讀檔後若出現亂碼替代字元（U+FFFD），不要送出，直接提示「檔案不是 UTF-8，請在 Excel 選『CSV UTF-8（逗號分隔）』另存」。
4. **批量填日期覆蓋備註**：`/api/tracked-items/bulk` 把現有備註改成「批量填寫」。改為保留原有備註，不改 notes。補具名測試。
5. **瀏覽器分頁標題**仍是「跨境車牌代辦 · 管理端」，改為「車牌管家 · 管理端」（`admin/index.html`）。

完成後跑 `cd api && npm test`、`cd admin && npm run check`、`cd admin && npm run build`，逐項報告。
