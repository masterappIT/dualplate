# 第一階段需求追加：公司狀態（含已註銷）

先讀 `AGENTS.md`。這是用戶新提出的需求，不是你之前的錯誤。

## 背景

部分兩地牌的**內地公司（內承單位）已被註銷**。現在系統會照樣替這些公司產生「工商年報」「匯算清繳」等提醒，造成假警報；公司組也無法表示「內地公司已註銷」。

自 2024-11-15 起，投資類指標延期不再核稅（見 `docs/requirements.md` §1.2），所以內地公司註銷後，兩地牌仍要照常管理（批文、CRP、保險、驗車等提醒不變）。

## 先修：上一輪退回（第 3 輪驗收）

0. **總覽窄螢幕卡片的欄位標籤不見了**。負責人在 390px 實測：每張卡片只剩一串值（「曲坤有限公司」「—」「—」「待錄入」「—」），看不出哪個是到期日、哪個是剩餘天數；對象連結也被置中。上一輪要求是「標籤與值整行顯示」，不是拿掉標籤。請改為每行「標籤｜值」（例如左側灰色小字「到期日」，右側值），對象連結靠左對齊。沒有操作時整行「操作」不顯示。修完在 390px 和 1280px 各看一次；無法使用瀏覽器時如實寫明。

## 要做的事

1. **公司狀態欄位**：`companies` 加 `status TEXT NOT NULL DEFAULT '存續'` 與 `status_changed_on TEXT`（一次性遷移）。允許值：`存續`、`經營異常`、`註銷中`、`已註銷`。`POST`／`PATCH /api/companies` 接受 `status`、`statusChangedOn`（日期驗證），非法值回 400。
2. **規則引擎**：
   - 公司 facts 加入 `status`
   - `已註銷` 的公司**不產生任何公司層級的到期項目**（包括手動到期與推算型），由引擎統一處理，不要只在個別規則加條件
   - `註銷中`、`經營異常` 照常產生提醒
   - 規則條件 `matchKeys` 加入 `companyStatus`，讓租戶可自訂規則只適用某些狀態
3. **兩地牌提示**：`GET /api/plate-assets/:id`（管理員）與 `GET /api/company-groups` 的兩地牌資料附上所屬公司組內各公司的狀態；兩地牌所屬組內的內地公司為 `已註銷` 或 `註銷中` 時，回傳 `warnings: ['內承單位已註銷']`（或「內承單位註銷中」）。
4. **管理端**：
   - 公司新增／編輯彈窗加「狀態」與「狀態變更日期」
   - 公司卡片顯示狀態標籤：存續（不顯示或灰色）、經營異常（琥珀）、註銷中（琥珀）、已註銷（灰底刪除線樣式或明確「已註銷」標籤）
   - 公司組內若內地公司已註銷，顯示「內地公司已註銷」，不要再顯示「尚未登記內地公司」
   - 兩地牌詳情頁的「公司組與指標」面板顯示上述 warnings
   - 管理總覽不出現已註銷公司的到期項目；客戶健康列表的公司數不計已註銷公司（另以「已註銷 N 間」顯示）
5. **測試**（具名，一情況一測試）：已註銷公司不產生公司到期項目；註銷中照常產生；狀態驗證；兩地牌 warnings；總覽不含已註銷公司項目；`companyStatus` 條件生效。

## 追加：官方免費接口

6. **香港公司註冊處開放數據 API**（官方、免費）：
   - 端點：`GET https://data.cr.gov.hk/cr/api/api/v1/api_builder/json/local/search?query[0][key1]=Brn&query[0][key2]=equal&query[0][key3]=<8位商業登記號碼>`（也支援 `Comp_name` + `begins_with`）
   - 實測回傳：`Brn`、`Chinese_Company_Name`、`English_Company_Name`、`Address_of_Registered_Office`、`Company_Type`、`Date_of_Incorporation`（格式 `DD-MM-YYYY`）、`Re-domiciliation_Date`
   - 新增 `POST /api/companies/:id/hk-lookup`（管理員，限香港公司，須已填 8 位登記號碼）：由伺服器呼叫上述接口，回傳查到的資料供確認；管理員確認後才寫入（名稱、成立日期）。不要自動覆蓋
   - 查無結果時回傳「公司註冊處查無此存續公司，請人工核實」，不自動改狀態
   - 逾時 10 秒、網絡錯誤要有清楚錯誤訊息；只用 Node 內建 `fetch`
   - 管理端公司編輯彈窗加「向公司註冊處查詢」按鈕，顯示查到的資料和「套用」按鈕
   - 測試用本機假伺服器模擬接口（用環境變數覆寫接口網址），不得在自動測試中連到真實網站
7. **內地公司狀態定期核對**（國家企業信用信息公示系統沒有 API，不做網頁抓取）：
   - 新增預設規則 `cn_status_check`「核對內地公司登記狀態」：對內地公司、非已註銷，每季一次（用 `yearly` 不足以表達，請新增計算方式 `periodic`，參數 `months`，以 1、4、7、10 月 1 日為期；可在規則設定修改）
   - `periodic` 的期數格式用 `YYYY-MM`（該期開始月份），完成記錄的期數驗證要同時接受 `YYYY` 與 `YYYY-MM`
   - 到期項目附官方網址 `https://www.gsxt.gov.cn/` 供員工打開查核；完成後標記本期完成，如發現註銷就在公司狀態更新
   - 加測試
