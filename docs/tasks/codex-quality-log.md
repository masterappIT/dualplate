# Codex 質量記錄

負責人每輪驗收後填寫，用來判斷 Codex 能力是否明顯變弱。

## 判斷「明顯變弱」的信號

- 同一類失誤在守則寫明後仍重複出現
- 退回項目數或嚴重錯誤數連續上升
- 改壞原本正常的功能、越界改動受保護的檔案
- 報告與實際不符（聲稱完成但沒做、測試結果造假）
- 同等規模任務耗時大幅增加，或明顯答非所問

出現任一信號，負責人須主動告知管理者。

## 環境備註

- 模型設定為 `gpt-6-sol`，經第三方轉發 `api.dkby.com`；Codex 啟動時提示「找不到模型資料，使用預設設定，可能影響表現」。如果轉發服務實際換了模型，能力可能突然變化，所以要逐輪記錄。
