# 客戶自行辦理後更新資料：設計要點（負責人 2026-10-17；第六節管理者已決定）

## 一、為什麼不能只靠「直接修改」

客戶現在可以直接改批文卡、車牌、車輛、司機和到期日，改了立即生效、員工再核對。這適合**改正填錯**，不適合**真的辦了變更**，原因：

1. 一次辦理會動到幾份文件。續期是「內地延期 → 港／澳續期 → 備案」，換車是「內地指標換車 → 港／澳牌證更新 → 海關／邊檢備案」。客戶只改批文卡，香港 CRP、澳門通行證、備案的日期仍是舊的。
2. 有些資料不在批文卡上：新車的保險、交強險、香港車輛牌照、首次註冊日期（推算驗車）；新司機的回鄉證、駕駛執照。
3. 直接改車輛的車牌號，舊車的保險、驗車日期會原封不動變成新車的，提醒全錯，舊車歷史也被蓋掉。
4. 員工在「客戶更新待核對」只看到零散欄位，分不清是改錯字還是辦了變更，也不知道要向客戶要哪些文件。

## 二、做法：先問「辦了變更，還是填錯？」

觸發點（任何一個）：

- 改批文卡的內地車牌、港澳車牌、駕駛人、通行口岸、商號、內承單位、有效期
- 上傳新批文卡，辨識出上述欄位和現有不同
- 改車輛的車牌號
- 按「續期／換車／換司機／其他」時選「已自己辦好」

選「填錯」→ 照現在直接改。選「辦了變更」→ 問辦了哪一種，進入對應的更新步驟（第三節）。

## 三、各類變更要更新什麼、要留意什麼

| 自行辦理 | 客戶要提供 | 系統要更新 | 特別留意 |
|---|---|---|---|
| **續期** | 新批文卡正反面；粵港：新 CRP；粵澳：新澳門通行證 | 批文有效期（自動從卡上讀）、CRP／澳門通行證到期日 | 客戶可能**只辦了一半**（內地延了、香港未續）：逐份文件問「已辦好／未辦」，未辦的照舊提醒。新批文開始日變了，「新批文備案期限」（183 天）會重新出現，要問備案辦了沒有 |
| **換車** | 新批文卡；新車行車證、保險單 | 建立新車記錄、牌照改綁新車；舊車保留作歷史並停止提醒；新車保險、交強險、香港車輛牌照、首次註冊日期 | **不可改舊車的車牌號**。90 天過關掛在牌照上，照常連續計算。新車缺的日期顯示「未錄入」，員工跟進 |
| **換／加司機** | 新批文卡背面；新司機回鄉證、駕駛執照 | 更新登記司機名單（主／副）；新司機證件到期日 | 被換走的司機，證件提醒要停止，否則會繼續提醒一個已不開這輛車的人 |
| **口岸變更** | 新批文卡；新 CRP | 通行口岸、CRP 到期日 | 只限粵港；口岸變了，備案可能也要重辦 |
| **商號／持有人變更** | 新批文卡；公司變更證明 | 商號、內承單位、牌照所屬公司組 | 會影響公司維護、報帳的歸屬，**不自動搬公司**，由員工核對後處理（避免把牌照搬錯公司） |
| **補領** | 新批文卡 | 卡面流水號 | 有效期不變；若辨識出有效期不同，提示員工核對 |
| **驗車** | 檢驗標誌或檢驗結果相片 | 該年度驗車記為完成 | 目前只有員工能標記完成，需要開放給客戶「標記已辦好」並附相片 |
| **備案** | 備案回執 | 備案到期日／新批文備案完成 | 同上 |

## 四、與我們的工作、收費的關係

1. **有開着的工單**：同一牌照有同類未結案工單（例如我們正在辦續期），客戶又說自己辦好了 → 員工待核對清單置頂提示「客戶表示已自行辦理，請確認後取消工單」，不自動取消。
2. **原屬我們代辦的項目**：委託範圍是「我們做」，客戶卻自己辦了 → 標明「客戶自行辦理」，讓管理者知道。**只是這一次自辦，不自動改成「客戶自理」**；要長期改由管理者在委託範圍改。
3. **收費**：客戶自辦不產生收費，結案收費的預填不涉及。年費客戶是否扣減，由管理者決定（見第六節）。
4. **責任記錄**：每次自辦都記下「客戶自行辦理，資料由客戶提供」，連同相片存檔。日後資料有誤時分得清責任。

## 五、提醒與通知

1. 客戶更新後，該項到期提醒立即按新日期計算，不再發舊的提醒。
2. 今日工作裏原本由我們跟進的那一項會消失：員工若已在跟進（已聯絡客戶），要在待核對清單看到是客戶自辦了，不是憑空消失。
3. 員工核對時對照客戶上傳的正本（今天已做好「查看正本」）；核對不符可以退回，並寫明原因給客戶。

## 六、管理者決定（2026-10-17）

1. 服務條款寫明：自行辦理的變更，須在 **7 天內**於客戶端更新。客戶端的更新入口同樣提示這句。
2. 年費客戶自辦了年費內的項目：**只記錄，不扣減**。
3. 提供「**不再續期**」選項（放棄指標、賣車）：選了即停止該牌照的提醒，交員工確認後處理。

## 七、建議實施順序

1. 修改時先問「辦了變更還是填錯」＋ 換車（風險最大：會把舊車資料帶到新車）
2. 續期（逐份文件已辦／未辦）
3. 換司機
4. 驗車、備案由客戶標記完成
5. 其餘（口岸、商號、補領）

## 八、實施狀態（負責人 2026-10-17）

已完成（第七節 1–3 項及「不再續期」）：

- 客戶端：牌照頁「續期／換車／換司機」先問「請我們代辦／已自己辦好」；改批文卡港澳車牌、駕駛人、有效期延後，或改車輛車牌、綁定車輛時，先問「辦了變更還是填錯」。新頁 `pages/self-change`（自行換車、自行續期、自行換司機、不再續期），頁內提示 7 天內更新。
- 後端：`api/src/self-handled.js`。換走的車、換走而沒有開其他牌照的司機、不再續期的牌照保留記錄，只停止提醒（`vehicles.retired_on`、`drivers.retired_on`、`plate_assets.stopped_on`，由 `computeDeadlines` 統一略過）。續期新到期日必須比現在的晚。
- 管理端：今日工作「客戶自行辦理待核對」（`SelfHandledChanges`），整件核對；核對時一併核對同一牌照的批文卡修改；退回須寫原因並通知客戶，不再續期退回即恢復提醒。

第七節第 4 項（同日完成）：客戶端到期項目中的「內地驗車／檢驗標誌」和「新批文備案期限」有「已辦好」，必須附相片（檢驗標誌／檢驗結果、備案回執）；只可標記現在仍未完成的那一期。標記即記為完成、停止提醒，管理端同一個清單整件核對；退回撤銷客戶的標記，照舊提醒（員工自己標記的不受影響）。海關及邊檢備案到期日本來已可由客戶直接修改，不另設標記。

第七節第 5 項（同日完成）：牌照頁「其他」可選「已自己辦好口岸變更／商號變更／補領」（口岸變更只限粵港），改批文卡的通行口岸、商號、內承單位、流水號時同樣先問「辦了變更還是填錯」。
- 口岸變更：更新批文卡通行口岸，可同時填新的香港 CRP 到期日；牌照的口岸欄仍由管理者按新卡設定，清單提示備案可能要重辦。
- 商號變更：只改批文卡上的商號／內承單位（可只填一項）；牌照所屬公司組不自動搬，清單提示員工核對。
- 補領：更新流水號（編號如有改變一併更新，不可與名下另一張卡重複）；新卡有效期與原來不同時提示員工核對。
- 「原來」的值以顧問核對前的卡面為準：客戶先改卡或上傳新卡、再說明是自己辦了變更，同樣可以提交（續期亦同）。

第七節全部完成。
