## 原因

拆分時有些模板用到的變數和函數沒有在組件內定義或從 `store.js` 引入。Vite 編譯不會報這類錯，只會在執行時崩潰。負責人用靜態檢查找到：

- `App.vue` → `selectedPlate`
- `views/VehicleDetail.vue` → `view`、`customerName`

## 要做的事

1. 修正上述未定義的引用
2. 負責人已新增檢查工具 `admin/scripts/check-template-refs.mjs`（`cd admin && npm run check`），會列出所有模板裡未定義的名稱；**必須通過**
3. 逐一核對每個頁面在錯誤修正後是否恢復：車輛詳情、兩地牌詳情（含批文卡）、案件詳情、建立案件、所有彈窗（新增客戶、開通客戶登入、登記車輛、登記兩地牌、登記出租、新增牌證、建立驗車任務）
4. 「案件工作台」的結構差異：比對拆分前後的模板，確認沒有遺漏元素
5. 你無法使用瀏覽器，所以請自行寫一個不需新依賴的檢查：用 `@vue/compiler-sfc` 編譯每個組件，確認沒有錯誤；並在報告中說明你如何確認每個彈窗都能打開（例如核對 `modal` 的每個值都有對應的模板分支）
