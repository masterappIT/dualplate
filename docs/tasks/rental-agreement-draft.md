# 兩地牌出租協議範本（負責人初稿 2026-10-18，待管理者提供參考範本後修改）

管理者 2026-10-18 決定：客戶可自行把牌照出租給別人使用；協議屬客戶與承租人雙方，按香港法律擬定，不需律師審閱；建議客戶以香港身份或香港公司簽署；客戶可修改細節；用語寫「出租、租金、承租人」。管理者稍後提供參考範本，屆時按範本修改本稿。

## 起草原則

1. **我們不是協議一方。** 協議只在出租人（客戶本人或其持牌公司）與承租人之間；我們只按出租人委託代辦手續或代收租金，條文寫明這一點，避免承租人向我們追討。
2. **出租的是「使用權」**，不寫轉讓指標或批文。批文、持牌公司始終屬出租人，由出租人（或其委託的我們）維護。
3. **換車、換司機的手續責任寫清楚**：由誰辦、費用誰付、辦好前不算開始使用，對應系統的「待換車」狀態。
4. **違規後果由承租人承擔**：兩地交通、海關、邊檢的罰款、扣分、走私或違法使用引起的後果；這是牌主最大的風險。
5. **批文出事時自動終止**：批文被取消、不能續期或持牌公司不能維持時，協議終止、按日退回租金，不算出租人違約。
6. 條文短、一條一事，客戶容易看懂和自己改。

`{{…}}` 是系統自動填入的地方（見文末對照表）；客戶在發出前可以修改任何文字，按「發給承租人」後鎖定為一個版本。

## 範本正文

**兩地牌照出租協議**

協議編號：{{協議編號}}　　簽署日期：{{簽署日期}}

**出租人**：{{出租人}}（{{出租人身份}}）
**承租人**：{{承租人}}　證件號碼：{{承租人證件}}　聯絡電話：{{承租人電話}}

**一、出租內容**
1. 出租人同意把以下兩地牌照的使用權出租給承租人：
   - 兩地牌照：{{牌照}}（批文卡編號 {{批文卡編號}}）
   - 持牌公司：{{持牌公司}}
2. 承租人使用的車輛：{{使用車輛}}；指定司機：{{司機}}。
3. 批文、批文卡及持牌公司始終屬於出租人。承租人只取得本協議期內的使用權，不得轉租、轉借或以任何方式讓第三者使用。

**二、租期**
1. 由 {{開始日期}} 至 {{結束日期}}。
2. 如須把承租人的車輛或司機登記到批文上，租期由手續辦妥、承租人可以使用之日起計；辦妥前不收租金。

**三、租金及付款**
1. 租金為 {{租金}}，{{週期}}繳付，每期於 {{收款日}} 日或之前付清。
2. 付款方式：{{收款方式}}。
3. 租金逾期 7 日仍未付清，出租人可以書面通知終止本協議，並按第八條處理。

**四、押金**
1. 承租人簽署本協議時支付押金 {{押金}}。
2. 協議終止、承租人履行第九條後 14 日內，出租人退回押金；可先扣除承租人未付的租金、罰款及按本協議應由承租人承擔的費用，並列明扣除項目。

**五、換車、換司機手續**
1. 把承租人的車輛或司機登記到批文上、以及協議終止後換回的手續，由 {{手續辦理方}} 辦理。
2. 官方收費及代辦費用由 {{手續費用承擔方}} 承擔。
3. 承租人須按要求提供辦手續所需的證件及資料，並配合驗車、拍照、簽署等安排。

**六、承租人責任**
1. 遵守內地、香港及澳門的交通、海關、邊檢及出入境法規，只作合法用途。
2. 使用期內的交通違例罰款、扣分、海關或邊檢處罰，以及因承租人或其司機的行為引起的一切後果，由承租人承擔；出租人因此受到的損失，承租人須全數賠償。
3. 不得利用車輛運載違禁品、走私或從事任何違法活動。如發生，出租人可即時終止本協議，押金不退，並保留追究的權利。
4. 承租人須自費為使用的車輛購買並維持有效的港澳車輛保險及內地交強險，保單須涵蓋整個租期。
5. 出租人或其代辦人通知要辦理年審、續期、備案等手續時，承租人須在通知的期限內配合。

**七、出租人責任**
1. 在租期內保持批文有效、持牌公司正常存續，並按時辦理續期、年審等手續（可委託代辦公司辦理）。
2. 如批文被取消、不能續期，或持牌公司不能維持，出租人須盡快通知承租人。這種情況下本協議自動終止，出租人按日退回已付但未使用的租金及押金，不另作賠償。

**八、提前終止**
1. 任何一方可以提前 {{通知期}} 日以書面（包括 WhatsApp、微信或電郵）通知對方終止本協議。
2. 承租人違反第三條第 3 款或第六條，出租人可以即時書面通知終止。
3. 提前終止時，已付租金按日計算多退少補。

**九、協議終止後**
1. 承租人須在終止後 7 日內配合辦理換回車輛及司機的手續，並交還出租人提供的證件、批文卡或其他物品。
2. 換回手續辦妥前，承租人仍須遵守第六條。

**十、代辦公司**
出租人可以委託 {{代辦公司}} 代辦本協議涉及的手續或代收租金。代辦公司只按出租人的委託行事，不是本協議的一方，不承擔本協議下出租人或承租人的責任。

**十一、個人資料**
承租人同意出租人及其代辦公司為履行本協議（包括辦理換車、換司機及收租）使用承租人提供的個人資料。

**十二、其他**
1. 本協議受香港特別行政區法律管轄。因本協議引起的爭議，雙方先友好協商；協商不成的，交由香港法院處理。
2. 本協議的修改須經雙方書面同意。
3. 承租人在網上確認本協議，與簽署具同等效力。雙方亦可另行簽署紙本，紙本與網上確認的版本內容須一致。

（簽署欄由系統附在協議下方：出租人、承租人各自手寫簽名，連同簽署人和時間；未簽的留空線，列印後也可以手簽。）

## 系統自動填入對照（2026-10-18 已實作，見 `api/src/renter-portal.js` 的 `agreementTemplate`）

| 佔位 | 來源 |
|---|---|
| 協議編號、簽署日期 | 發出時產生 |
| 出租人、出租人身份 | 出租人選客戶本人 →「個人」或「公司」（委託人類型）；選持牌公司 →「香港公司／澳門公司」及公司名稱 |
| 承租人、承租人證件、承租人電話 | 新增出租時填（證件號碼為新欄位） |
| 牌照、批文卡編號、持牌公司 | 牌照資料 |
| 使用車輛、司機 | 新增出租時選或填 |
| 開始日期、結束日期 | 新增出租時填；未定寫「雙方另行約定」 |
| 租金、週期、收款日、押金、收款方式 | 新增出租時填；收款方式「直接付給出租人」或「付給代辦公司」 |
| 手續辦理方 | 交給我們代理 →「出租人委託的代辦公司」；自行負責 →「出租人」 |
| 手續費用承擔方 | 預設「承租人」，客戶可改 |
| 通知期 | 預設 30 |
| 代辦公司 | 設定裏的公司名稱（IM MASTER INC. LIMITED） |

現有的「車輛使用安排確認書」範本（`api/src/renter-portal.js` 的 `defaultTemplate`）在做 5A 時換成本範本；已發出的舊確認書不變。

## 請管理者確認

1. **押金扣除、逾期 7 日可終止、退押金 14 日、換回手續 7 日、提前通知 30 日**：這些天數是我按一般租賃習慣定的預設，客戶可以改。
2. **手續費用預設由承租人承擔**：換車、換司機是為承租人而辦，一般由承租人付。
3. **第十條寫明我們不是協議一方**：保護公司；如你想以「見證人」或其他身份出現，請告訴我。
4. 參考範本到後，我會逐條對照，保留範本裏有而本稿沒有的條文，並列出差異給你看。

## 手寫簽名（管理者 2026-10-18 加上）

- 每一版協議雙方各簽一次：客戶按「發給承租人」前在客戶端簽名（網頁版手指或滑鼠都可以），承租人打開連結時填姓名並手寫簽名才可以同意。
- 協議改了重新發出，版本加一，雙方要重簽；只是重發連結（協議沒改），沿用這一版的簽名。
- 簽名以 PNG 保存（每份 600 KB 內），連同簽署人、時間和網絡地址；協議下方顯示雙方簽名，列印版一併帶出。
- 系統只檢查「有筆畫」和檔案是 PNG，不判斷簽名像不像本人。
