# 設計：逐件委託、客戶事項清單與收費（負責人 2026-10-17，管理者逐點確認）

取代原 `scope-matrix-brief.md`（6 個大項分段方案，已作廢）。本任務由負責人親自實作，分支 `scope-items`。

## 一、管理者確認的原則

1. 持有兩地牌的香港、內地、澳門公司大多是殼公司，客戶不經營。
2. 委託範圍按**香港公司、澳門公司、內地公司、車牌**分類，另有**按次業務**。
3. 每位客戶的委託內容都不同：每位客戶有自己的**事項清單**，預設只放最需要的，需要時加、不需要時移除。
4. 「審計及利得稅」不要：該規則改為停用（不刪除），要時在規則頁打開、再加到客戶清單。
5. 每件事兩個設定：**誰做**（逐間公司、逐個牌照）與**怎樣收費**（按客戶）。
6. 一次性業務（換車、換司機、補領等）可另外收費：價目表放預設價，客戶特別價放在他的委託範圍，工單結案自動帶入。
7. 客戶端只顯示委託了甚麼，**不顯示價錢**。
8. 員工結案按次收費的工單：系統自動產生一筆「未收」收費，管理者核對。
9. 價目表**按路線分開**（粵港、粵澳各一個價）。

## 二、三層結構

| 層 | 內容 | 在哪裏改 |
|---|---|---|
| 事項總表 | 所有到期規則＋內建事項（每月報帳、租金跟進） | 規則頁；開關只用來淘汰整件事 |
| 客戶事項清單 | 這位客戶要管的事項 | 客戶詳情 →「委託範圍」：加事項、移除 |
| 逐個對象 | 每間公司、每個牌照每件事誰做 | 同上，矩陣逐格或整欄 |

- 不在客戶清單上的事：系統完全不管，不提醒我們、也不提醒客戶；已填的日期和記錄保留，加回來即恢復。
- 「客戶自理」：在清單上，只提醒客戶，不產生我們的工作。
- 未改過清單的客戶，清單＝全部啟用中的事項（新客戶即如此）。第一次加或移除時才固定成自己的清單。
- 規則頁新增規則時，可選「加到所有客戶的事項清單」（預設勾選）。

## 三、事項分類

| 分類 | 來源 |
|---|---|
| 香港／澳門／內地公司 | 公司規則，按規則條件的司法區歸類；沒有限定司法區的規則三類都出現 |
| 內地公司（內建） | 每月報帳報稅（`monthly_filing`） |
| 車牌 | 牌照、車輛、司機規則，另分小組：批文與通行證、備案、車輛、司機、過關、出租（內建 `rent_overdue`）、其他 |

規則加 `item_group`；自訂車牌類規則在規則彈窗選小組。

## 四、誰做

- 選項：我們做／外包（單位名）／客戶自理（本公司自有客戶不可選客戶自理）。
- 沒有記錄時：按客戶最近套用的委託範本推算（新增的公司、牌照因此自動跟隨範本）；從未套用範本則為「我們做」。
- 範本：全權托管（全部我們做）、只管牌照（公司類客戶自理）、牌照＋內地公司（香港、澳門公司客戶自理）。
- 每月報帳選外包時，外包單位從會計公司名單選，與報帳頁共用 `companies.accounting_firm_id`。
- 舊 API 傳大項代碼（`company_upkeep` 等）時，展開為該大項下、適用於該對象且在客戶清單內的全部事項。

## 五、收費（第二輪）

- 價目表（設定）：每件事×路線一個預設：年費內／按次收費（幣種、金額）／不收。一次性業務即工單範本（已按路線分開），預設按次；定期事項預設年費內。
- 客戶特別價：在客戶委託範圍的欄標題及「按次業務」段設定；只存與預設不同的。
- 工單結案：管理者結案時代辦費預填客戶價；年費內顯示「含在年費，不另收」。員工結案時自動產生「未收」收費，備註「員工結案自動產生，請核對」。
- 定期事項標記「已辦好」時，如按次收費，提示記一筆收費並預填金額，可略過。
- 收費只限管理者可見；客戶端不顯示價錢。

## 六、畫面

委託範圍抽屜由上到下：香港公司、澳門公司、內地公司、車牌、按次業務（第二輪），沒有對象的段不顯示。
- 公司段：每行一間公司（名稱下顯示所屬牌照），每欄一件事。
- 車牌段：每欄一個小組，格子顯示整組負責方，不一致時「混合」；按牌照展開逐件調整。
- 欄標題選單：整欄設定誰做、從清單移除；段尾「＋ 加事項」從總表加回。
- 提交前顯示影響：到期提醒改為只提醒客戶／不再提醒的數量，及相關進行中工單。

## 七、資料遷移（一次性）

1. 每條現行的大項記錄，展開為該大項下適用於該對象的逐件記錄（負責方、外包單位、開始日期不變），舊記錄結束並保留為歷史。香港公司舊的「每月報帳」沒有對應事項，只結束。
2. `hk_audit_tax` 規則停用。
3. 現有客戶不固定清單（＝全部啟用事項），所以遷移後甚麼都不會消失。
4. 正式環境升級前先備份；升級後核對李先生每項到期事項的負責方與升級前一致。
