# 任務：香港公司英文名稱、內地公司簡體名稱（負責人 2026-10-17）

開始前先讀 `AGENTS.md`，再讀本文件。正式環境部署已驗收（2026-10-17），可以開始。**本任務不需要任何雲端操作，也不要發布。**

## 一、管理者的要求

1. **香港公司必須有英文名稱。**
2. **內地公司名稱必須用簡體字。**

理由：兩邊官方登記就是這樣——香港公司註冊處登記英文名（批文卡上也印英文名），內地營業執照只有簡體名。報關、批文、報稅文件都要和官方登記一字不差。

本機資料已在 2026-10-17 清空，沒有舊資料要遷移；測試和截圖用的客戶、公司、牌照請自行建立。沒有英文名稱的舊資料照第二節第 5 點顯示「未填英文名稱」，由負責人上線後處理。

## 二、香港公司英文名稱

1. **資料**：`companies` 加欄位 `name_en TEXT`（用 `db.js` 現有的 `addColumn`）。API 欄位名 `nameEn`。
2. **規則**（`POST /api/companies`、`PATCH /api/companies/:id`）：
   - 司法區為「香港」：英文名稱必填。新增時沒填、或修改後結果為空 → 400「香港公司必須填寫英文名稱」。舊資料沒有英文名稱的，**修改任何欄位時都要求補上**。
   - 只接受英文字母、數字、空格和常見符號 `. , & ( ) ' - /`；不得含中文 → 400「英文名稱只可用英文字母、數字和常見符號」。去掉頭尾空白，連續空白合併為一個；**不要自動轉大寫**，照輸入保存。長度上限 160。
   - 司法區為「內地」或「澳門」：不顯示這個欄位，存成空字串（做法同 `company_number` 只屬香港）。
   - 型別錯誤、`null`、陣列都要回 400，不可 500。
3. **香港公司註冊處查詢**：查詢結果已有 `englishName`。「套用」時一併填入英文名稱欄。
4. **牌照 CSV 匯入**（`api/src/plate-import.js`、`server.js` 匯入段）：加一欄「香港公司英文名」，放在「香港／澳門公司」右邊，範本同步更新。
   - 路線「粵港」而且香港公司是**新建**的，這欄必填，沒填的那一行在預覽中列為錯誤。
   - 香港公司已存在的，這欄可留空；有填但和現有不同，在預覽中列為錯誤，不要覆蓋。
   - 路線「粵澳」這欄留空；有填就忽略。
   - 舊的、沒有這一欄的 CSV 照常可讀，只是新建的香港公司會因缺英文名稱而報錯。
5. **顯示**：凡是顯示香港公司名稱的地方，中文名稱下面以次要文字顯示英文名稱，不另加標籤。沒有英文名稱的舊資料顯示「未填英文名稱」，用警示色。
   - 管理端：公司頁、公司編輯彈窗（香港公司在中文名稱下面加「英文名稱」欄）、客戶結構、牌照詳情、報帳頁等。
   - 客戶端：**本任務特准**修改 `mobile/src/pages/companies/companies.vue` 的公司名稱顯示，和 `api/src/customer-routes.js` 中為了回傳 `nameEn` 而必須改的查詢欄位。只可改這兩處，其他客戶端頁面和版面不得改動。

## 三、內地公司簡體名稱

1. **對照表**：負責人已建立 `api/src/hans-chars.js`（3,048 對繁體 → 簡體單字）。**不得修改這個檔案**；需要例外字時在你的程式裏處理。
2. **建一個共用函數**（例：`api/src/hans.js`）：
   - `toSimplified(text)`：逐字轉換。
   - `traditionalChars(text)`：找出名稱裏的繁體字。
   - **允許清單**：有些字在簡體也是正確寫法，不可當成繁體字拒絕，至少包括「乾 於 著 瞭 藉 俱」（例：乾坤、於姓、著名、瞭望、狼藉、俱乐部）。這些字在對照表裏會被轉掉，不能當成繁體字拒絕，每個字都要寫測試。如果發現其他同類字，在報告列出，由負責人決定，不要自行擴充。
3. **新增／修改公司**（司法區為「內地」）：名稱含繁體字 → 400，訊息列出字和建議，例：「內地公司名稱須用簡體字（貿→贸、廣→广），建議：广州远星商贸有限公司」。回應帶 `suggestion` 欄位。
4. **管理端公司彈窗**：收到這個錯誤時，在名稱欄下方顯示建議名稱和「改用建議名稱」按鈕，按一下就填入。不要自動改掉用戶輸入的內容，不用瀏覽器 `prompt()`。
5. **牌照 CSV 匯入**：管理者手上的表格多用繁體，所以「內地公司」一欄**自動轉為簡體**（允許清單內的字保持不變）再比對和建立公司，不報錯。預覽中要清楚顯示「已轉為簡體：廣州遠星商貿有限公司 → 广州远星商贸有限公司」。比對現有公司時，用轉換後的名稱比對。
6. **括號**：內地公司名稱的半形括號 `()` 一律轉為全形 `（）`，新增、修改和匯入都要這樣處理。這是內地營業執照的寫法。
7. 香港、澳門公司的中文名稱**不轉換**。
8. 介面文字仍用繁體；只有內地公司名稱這筆資料是簡體。

## 四、測試（一個情況一個具名測試）

至少要覆蓋：
- 香港公司缺英文名稱，新增和修改都要拒絕。
- 英文名稱為空白、`null`、陣列或數字。
- 英文名稱含中文。
- 內地、澳門公司送 `nameEn` 時被清空。
- 註冊處查詢套用英文名稱（在前端實測）。
- 內地名稱含繁體字被拒，並回傳正確建議。
- 允許清單逐字測試。
- 半形括號轉為全形。
- CSV 匯入：繁體內地名稱自動轉換。
- CSV 匯入：轉換後與現有公司同名時不重複建立。
- CSV 匯入：新建香港公司缺英文名稱時報錯。
- CSV 匯入：已存在的香港公司英文名稱不同時報錯。
- CSV 匯入：沒有新欄位的舊 CSV。
- 別的租戶的公司 ID 回 404。
- 客戶帳號越權回 403。
- 客戶端公司接口回傳 `nameEn`。
