## 二、必須修正

1. **連線終點壓住表盤標籤**：牌照全景、權限全景、口岸星圖裡，中心到一級表盤的連線終點小圓點蓋在「客戶」「員工」「口岸待補」字上（見 `complete-staff-1366.png` 的「員工」、`latest-port-1366.png` 的「口岸待補」）。連線應止於表盤圓周，標籤不可被任何線或點遮住。
2. **零值不可用警示色**：摘要列「已註銷內地公司 0」用了琥珀色；「停用帳號 0」「30 天未登入 0」用了紅色。數值為 0 時一律用正文色，大於 0 才用警示色。
3. **390px 全景重疊**：`complete-plate-390.png` 的中心標籤「牌照全景／7 個牌照」壓在公司、牌照表盤上，表盤的連線點也壓進中心印章。窄屏時要按寬度縮小半徑和表盤，或改為上下排列；三個表盤、中心印章和所有標籤互不重疊。
4. **不照搬用字**：權限全景的一級表盤叫「角色」，追溯鏈也寫「角色」。這是腳手架用詞，`AGENTS.md` 明確禁止。改為「權限級別」（值：管理者、員工）。另外「管理者不足」意思不清，改為「只有一位管理者」並加說明：停用或離職時沒有人能管理帳號。
5. **單位用自然量詞**：「客戶 3 筆」「公司 5 筆」「牌照 7 筆」改為「3 位客戶」「5 間公司」「7 個牌照」，員工用「位」。中心的「16 筆資料」改為有意義的說法，例如「2 位員工 · 12 項功能」。
6. **到期日曆不可讀**（`lead-today-1366.png`）：
   - 熱力格沒有任何日期或星期標示。要加星期表頭（一至日）和每週起始日期，並標出今天。
   - 標題寫「未來 12 週」，但已逾期的 3 項放在最後一格。已逾期項目不屬於未來，不放進格子；在格子上方另列一行「已逾期 3 項」（紅色，點擊篩選列表）。
   - 顏色按該日最嚴重的狀態（逾期紅、7 天內琥珀、其餘綠），不要只用一種灰綠的深淺。
7. **到期趨勢曲線**：
   - 平滑曲線在 0 附近會衝到基線以下，而數量不可能是負數或小數。改用單調插值（monotone）或折線，並把 Y 軸刻度限制為整數。
   - 填色用了灰色漸層，改用本產品的 `--jade` 淡色。
   - 390px 時 X 軸標籤換成兩行，和數據點對不上（`lead-today-390.png`）。窄屏改用短標籤（「10月」「11月」……，跨年處寫「1月 2027」），保持一行、和數據點對齊。
8. **本週進度的空狀態**：本週沒有到期項目時，表盤顯示「0 項 已辦」，下面又是「0 / 0 項」，看不懂。改為顯示「本週沒有到期項目」，表盤用終態，不播動畫。
9. **自查漏報**：你自己的 `heat-full-1366.png` 上清楚寫著「到期視圖載入失敗：找不到此頁」，報告卻寫「主控台錯誤：無」並當作已檢視。原因是新接口要等負責人重啟 API 才生效。以後截圖上出現任何錯誤文字、空白或「載入失敗」，**必須在報告寫出來**，並請負責人重啟；不可只看 `.txt` 的主控台結果。
10. **重複的到期資料組裝**：`api/src/view-routes.js` 第 17 行起整段複製了 `api/src/phase1-routes.js` 第 221 行的 owners 組裝。請抽成一個共用函數（例如 `api/src/deadline-owners.js` 的 `deadlineOwners(tenantId)`），由 `phase1-routes.js` 和 `view-routes.js` 共用，行為不變，現有測試全部照過。`customer-routes.js` 不要動。
11. **客戶詳情的兩組分頁擠在一起**：「概覽／公司組／牌照…」和「表格／結構／時間軸」並排，看起來像同一組分頁。視圖切換應改為放在內容面板標題右側的小型切換（和牌照頁、員工頁的位置一致），只在有對應視圖的分頁出現。
12. **客戶結構畫布連線交叉過多**（`structure-separated-1366.png`）：每一欄要按上一欄父節點的順序排列，子節點靠近父節點，減少交叉。名稱被截斷時，懸停或選中要能看到全名。
