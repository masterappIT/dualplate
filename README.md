# dualplate · 車牌管家

粵港澳兩地車牌代辦 CRM。

此倉庫提供客戶端（微信小程序、iOS／Android App 資源及 H5 預覽）、管理端和本機可運行的 API。服務目錄包括粵港／粵澳新申請、續期、換車、換司機、口岸變更、持有人資料變更、補領、驗車、海關／邊檢備案及其他要求。

所有政策、條件、表格及流程文字均以政府或主管部門官方來源為準；每項業務附來源索引。產品提醒天數和公司內部節點屬系統設計，並非官方辦理承諾。未核實的申請資格或驗車要求維持人工核對。
